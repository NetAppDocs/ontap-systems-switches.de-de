= Warnmeldungen für den Zustandsmonitor des Ethernet-Switches beheben
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Warnmeldungen, die vom Ethernet Switch Health Monitor (CSHM) ausgelöst werden, wenn ein Fehler, ein Risiko oder ein kritischer Zustand bei einem Netzwerk-Switch in Ihrem ONTAP Cluster erkannt wird, können behoben werden.

Wenn Warnmeldungen ausgegeben werden, meldet der Systemzustandsbericht einen beeinträchtigten Status für den Cluster.  Die ausgelösten Warnmeldungen enthalten die Informationen, die Sie benötigen, um auf eine Beeinträchtigung des Systemzustands zu reagieren.

Um die verfügbaren Warnmeldungen des Ethernet-Switch-Integritätsmonitors anzuzeigen, führen Sie folgenden Befehl aus: `system health alert definition show -monitor ethernet-switch`

Weitere Einzelheiten zur erweiterten Behebung von Warnmeldungen finden Sie im Knowledge Base Artikel https://kb.netapp.com/on-prem/ontap/OHW/OHW-KBs/Cluster_Switch_Health_Monitor_CSHM_Alert_Resolution_Guide["Leitfaden zur Behebung von Warnungen des Switch Health Monitor"^].
