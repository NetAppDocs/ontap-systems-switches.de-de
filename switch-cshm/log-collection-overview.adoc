= Übersicht der Protokollsammlung
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn die Protokollerfassung eingerichtet ist, können Sie eine stündliche Erfassung periodischer Daten aktivieren, die von AutoSupport gesammelt werden, und detaillierte Supportprotokolle anfordern.

Die Protokollerfassung unterstützt bei der Fehlerbehebung von Netzwerk-Switch-Problemen, indem automatisch Switch-Protokolle und Diagnosedaten gesammelt werden. Es ist möglich, periodische Daten planmäßig über AutoSupport zu erfassen oder eine bedarfsorientierte Erfassung auszulösen, wenn detaillierte Protokolle zur Fehlerbehebung spezifischer Probleme benötigt werden. Die erfassten Protokolle bieten Einblick in den Zustand der Switches, Konfigurationsänderungen und Netzwerkereignisse.

Weitere Einzelheiten finden Sie unter link:config-log-collection.html["Protokollerfassung konfigurieren"].
