= Cisco Nexus 9336C-FX2 Shared Switch auf Werkseinstellungen zurücksetzen
:allow-uri-read: 


[role="lead"]
Der Cisco Nexus 9336C-FX2 Shared Switch wird auf die Werkseinstellungen zurückgesetzt, indem die aktuelle Switch-Konfiguration gelöscht und der Switch auf seine ursprünglichen Einstellungen zurückgesetzt wird.

.Informationen zu diesem Vorgang
* Sie müssen über die serielle Konsole mit dem Switch verbunden sein.
* Diese Aufgabe setzt die Konfiguration des Managementnetzwerks zurück.


.Schritte
. Löschen Sie die vorhandene Konfiguration:
+
`write erase`

+
[listing, subs="+quotes"]
----
(cs2)# *write erase*

Warning: This command will erase the startup-configuration.
Do you wish to proceed anyway? (y/n) [n] *y*
----
. Laden Sie die Switch-Software neu:
+
`reload`

+
[listing, subs="+quotes"]
----
(cs2)# *reload*

This command will reboot the system. (y/n)? [n] *y*
----
+
Das System wird neu gestartet und der Konfigurationsassistent wird aufgerufen. Wenn Sie während des Startvorgangs die Aufforderung „Auto Provisioning abbrechen und mit der normalen Einrichtung fortfahren?“ erhalten, (ja/nein)[n]“, sollten Sie mit *ja* antworten, um fortzufahren.



.Was kommt als nächstes
Nachdem Sie Ihre Schalter zurückgesetzt haben, können Sielink:configure-switch-overview-9336c-shared.html["neu konfigurieren"] sie nach Bedarf.
