= Installations- und Einrichtungsworkflow für NVIDIA SN2100 Cluster Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Mit diesem Workflow lassen sich NVIDIA SN2100 Cluster Switches in einer ONTAP Umgebung installieren und konfigurieren. Der SN2100 ist ein 10/25/40/100 GbE Switch mit Cumulus Linux, der ONTAP Cluster mit mehr als zwei Knoten unterstützt.

Diese Arbeitsschritte dienen der Installation und Einrichtung Ihrer NVIDIA SN2100 Switches.

[role="quick-margin-para"]
Überprüfen Sie die Komponenten und Teilenummern für den Cluster-Switch SN2100.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:required-documentation-sn2100-cluster.html["Überprüfen Sie die erforderlichen Unterlagen"]
[role="quick-margin-para"]
