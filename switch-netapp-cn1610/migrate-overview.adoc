= Überprüfung der Migrationsoptionen für NetApp CN1610 Cluster Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Migrationsoptionen für den Wechsel von einem Zwei-Knoten Cluster ohne Switches zu einem Cluster mit Switches unter Verwendung von NetApp CN1610 Cluster Switches sollten geprüft werden. Das Verfahren hängt davon ab, ob zwei dedizierte Cluster-Netzwerk-Ports oder ein einzelner Cluster-Port pro Controller vorhanden sind.

Die meisten Systeme benötigen zwei dedizierte Cluster-Netzwerkanschlüsse an jedem Controller.

FAS22xx-Knoten erlauben einen einzelnen Cluster-Port pro Controller.

Es stehen zwei Migrationsoptionen zur Verfügung:

* link:migrate-switched-netapp-cn1610.html["Migration von einem Cluster ohne Switches zu einer geschalteten NetApp CN1610 Clusterumgebung"]
* link:migrate-fas22xx-systems.html["Migration von einem Cluster ohne Switches (FAS22xx-Systeme mit einer einzigen Cluster-Netzwerkverbindung)"]
