= Informationen zu NetApp CN1610 Cluster Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der NetApp CN1610 ist ein mit einer hohen Bandbreite verwalteter Layer 2 Cluster Switch, der 16 10-Gigabit-SFP+-Ports bereitstellt. Auf dieser Seite werden die Funktionen des Switches und seine Rolle im ONTAP Clusternetzwerk dargestellt.

Der Switch verfügt über redundante Netzteile und Lüftereinschübe, die Hot-Swapping für hohe Verfügbarkeit unterstützen. Dieser 1U Switch kann in einem Standard-19-Zoll NetApp 42U-Systemschrank oder in einem Schrank eines Drittanbieters installiert werden.

Der Switch unterstützt die lokale Verwaltung über den Konsolenport oder die Fernverwaltung per Telnet oder SSH über eine Netzwerkverbindung. Der CN1610 verfügt über einen dedizierten 1-Gigabit-Ethernet-RJ45-Managementport für die Out-of-Band-Switch-Verwaltung. Der Switch kann über die Eingabe von Befehlen in die Kommandozeilenschnittstelle (CLI) oder mithilfe eines SNMP-basierten Netzwerkmanagementsystems (NMS) verwaltet werden.
