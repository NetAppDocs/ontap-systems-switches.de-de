= Workflow zur Migration von Clustern ohne Switches zu Zwei-Knoten-Clustern mit Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die folgenden Workflow-Schritte beschreiben die Migration von einem Zwei-Knoten Cluster ohne Switches zu einem Zwei-Knoten Cluster mit Cisco Nexus 3132Q-V Cluster-Netzwerk-Switches.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:migrate-switchless-to-switched-requirements.html["Migrationsanforderungen"]
[role="quick-margin-para"]
Die Anforderungen und Beispielinformationen zum Migrationsprozess werden dargestellt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:migrate-switchless-prepare-to-migrate.html["Vorbereitung auf die Migration"]
[role="quick-margin-para"]
Bereiten Sie Ihre Cluster ohne Switches auf die Migration zu Zwei-Node-Switch-Clustern vor.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:migrate-switchless-configure-ports.html["Konfigurieren Sie Ihre Ports"]
[role="quick-margin-para"]
Ports für die Migration von Cluster ohne Switches mit zwei Knoten zu Cluster mit Switches mit zwei Knoten konfigurieren.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]link:migrate-switchless-complete-migration.html["Migration abschließen"]
[role="quick-margin-para"]
Die Migration von Clustern ohne Switches zu Zwei-Knoten-Clustern mit Switches ist abgeschlossen.
