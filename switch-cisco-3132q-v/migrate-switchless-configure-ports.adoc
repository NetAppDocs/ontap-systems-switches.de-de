= Ports für die Migration von Cluster ohne Switches zu Cisco Nexus 3132Q-V Cluster Switches konfigurieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ports für die Migration von einem Zwei-Knoten Cluster ohne Switches zu einem Zwei-Knoten Cluster mit Switches unter Verwendung von Cisco Nexus 3132Q-V Cluster Switches konfigurieren.

.Schritte
. Auf den Nexus 3132Q-V Switches C1 und C2 sind alle zu den Nodes gerichteten Ports C1 und C2 zu deaktivieren, die ISL-Ports jedoch nicht.
+
.Beispiel anzeigen
[%collapsible]
====
Das folgende Beispiel zeigt Ports 1 bis 30, die auf den Nexus 3132Q-V Cluster Switches C1 und C2 mithilfe einer in RCF unterstützten Konfiguration deaktiviert sind `NX3132_RCF_v1.1_24p10g_26p40g.txt`:

[listing]
----
C1# copy running-config startup-config
[########################################] 100%
Copy complete.
C1# configure
C1(config)# int e1/1/1-4,e1/2/1-4,e1/3/1-4,e1/4/1-4,e1/5/1-4,e1/6/1-4,e1/7-30
C1(config-if-range)# shutdown
C1(config-if-range)# exit
C1(config)# exit

C2# copy running-config startup-config
[########################################] 100%
Copy complete.
C2# configure
C2(config)# int e1/1/1-4,e1/2/1-4,e1/3/1-4,e1/4/1-4,e1/5/1-4,e1/6/1-4,e1/7-30
C2(config-if-range)# shutdown
C2(config-if-range)# exit
C2(config)# exit
----

. Die clus1-Schnittstelle auf den physischen Port migrieren, der clus2 hostet:
+
`network interface migrate`

+
Dieser Befehl ist von jedem lokalen Knoten auszuführen.

+
.Beispiel anzeigen
[%collapsible]
====
[listing]
----
cluster::*> network interface migrate -vserver Cluster -lif n1_clus1 -source-node n1
-destination-node n1 -destination-port e4e
cluster::*> network interface migrate -vserver Cluster -lif n2_clus1 -source-node n2
-destination-node n2 -destination-port e4e
----

====
. [[step10]]Das Kabel von e4a am Node n1 entfernen.
+
Es kann auf die laufende Konfiguration Bezug genommen und der erste 40 GbE Port am Switch C1 (Port 1/7 in diesem Beispiel) mit e4a auf n1 unter Verwendung unterstützter Kabel auf Nexus 3132Q-V verbunden werden.

+

NOTE: Beim Wiederanschließen von Kabeln an einen neuen Cisco Cluster Switch müssen die verwendeten Kabel entweder Glasfaserkabel oder von Cisco unterstützte Kabel sein.

. Das Kabel von e4a an Node n2 abziehen.
+
Sie können die laufende Konfiguration konsultieren und e4a mit dem nächsten verfügbaren 40 GbE Port auf C1, Port 1/8, unter Verwendung unterstützter Kabel verbinden.

. Alle zum Knoten führenden Ports an C1 aktivieren.
+
.Beispiel anzeigen
[%collapsible]
====
Das folgende Beispiel zeigt die Aktivierung der Ports 1 bis 30 auf den Nexus 3132Q-V Cluster-Switches C1 und C2 mit der in RCF unterstützten Konfiguration `NX3132_RCF_v1.1_24p10g_26p40g.txt`:

[listing]
----
C1# configure
C1(config)# int e1/1/1-4,e1/2/1-4,e1/3/1-4,e1/4/1-4,e1/5/1-4,e1/6/1-4,e1/7-30
C1(config-if-range)# no shutdown
C1(config-if-range)# exit
C1(config)# exit
----
