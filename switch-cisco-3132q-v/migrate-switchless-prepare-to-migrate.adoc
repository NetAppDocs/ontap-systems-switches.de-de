= Vorbereitung der Migration von einem Cluster ohne Switches zu Cisco Nexus 3132Q-V Cluster Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ihr Zwei-Knoten Cluster ohne Switches kann für die Migration zu einem Cluster mit Switches unter Verwendung von Cisco Nexus 3132Q-V Cluster Switches vorbereitet werden.

.Schritte
. Wenn AutoSupport auf diesem Cluster aktiviert ist, unterdrücken Sie die automatische Fallerstellung durch Aufruf einer AutoSupport -Nachricht:
+
`system node autosupport invoke -node * -type all - message MAINT=xh`

+
_x_ ist die Dauer des Wartungsfensters in Stunden.

+
[NOTE]
====
Die AutoSupport Meldung benachrichtigt den technischen Support über diese Wartungsaufgabe, sodass die automatische Fallerstellung während des Wartungsfensters unterdrückt wird.

====
. Ermitteln Sie den administrativen oder operativen Status jeder Clusterschnittstelle:
+

+
`network port show`

. Es sollte geprüft werden, ob die entsprechenden RCFs und das Image gemäß den Anforderungen auf den neuen 3132Q-V Switches installiert sind, und ob alle notwendigen Standortanpassungen wie Benutzer und Passwörter, Netzwerkadressen und Ähnliches vorgenommen wurden.
+
Beide Switches müssen jetzt vorbereitet werden. Wenn ein Upgrade der RCF- und Image-Software erforderlich ist, sind die folgenden Schritte zu befolgen:

+
.. Zur link:https://mysupport.netapp.com/site/info/cisco-ethernet-switch["Cisco Ethernet-Switches"^] NetApp Support Site wechseln.
.. Der verwendete Switch und die erforderlichen Softwareversionen sind in der Tabelle auf dieser Seite zu notieren.
.. Die passende Version von RCF herunterladen.
.. Auf der Seite *Beschreibung* die Option *WEITER* auswählen, die Lizenzvereinbarung akzeptieren und anschließend den Anweisungen auf der Seite *Download* folgen, um die RCF herunterzuladen.
.. Die passende Version der Image-Software herunterladen.


. Auf der Seite *Beschreibung* die Option *WEITER* auswählen, die Lizenzvereinbarung akzeptieren und anschließend den Anweisungen auf der Seite *Download* folgen, um die RCF herunterzuladen.
