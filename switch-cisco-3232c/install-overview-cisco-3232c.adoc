= Installations- und Einrichtungsablauf für Cisco Nexus 3232C Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cisco Nexus 3232C Switches können als Cluster-Switches in Ihrem AFF oder FAS Cluster verwendet werden. Cluster-Switches ermöglichen den Aufbau von ONTAP Clustern mit mehr als zwei Knoten.

Die folgenden Arbeitsschritte dienen der Installation und Einrichtung Ihres Cisco Nexus 3232C Switch.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:configure-reqs-3232c.html["Konfigurationsanforderungen"]
[role="quick-margin-para"]
Die Konfigurationsanforderungen für den 3232C Cluster-Switch werden dargestellt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:required-documentation-3232c.html["Erforderliche Dokumentation"]
[role="quick-margin-para"]
Die spezifische Dokumentation zu Switch und Controller bietet Anleitungen zur Einrichtung Ihrer 3232C Switches und des ONTAP Clusters.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:smart-call-home-3232c.html["Anforderungen für Smart Call Home"]
[role="quick-margin-para"]
Überprüfen Sie die Anforderungen für die Cisco Smart Call Home-Funktion, die zur Überwachung der Hardware- und Softwarekomponenten in Ihrem Netzwerk verwendet wird.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]link:install-hardware-workflow.html["Installieren Sie die Hardware"]
[role="quick-margin-para"]
Installieren Sie die Switch-Hardware.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Fünf"]link:configure-software-overview-3232c-cluster.html["Konfigurieren der Software"]
[role="quick-margin-para"]
Konfigurieren Sie die Switch-Software.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sechs"]link:../switch-cshm/config-overview.html["CSHM konfigurieren"]
[role="quick-margin-para"]
Konfigurieren Sie die Zustandsüberwachung der Switches.
