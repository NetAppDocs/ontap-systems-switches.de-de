= Arbeitsablauf für die Hardwareinstallation von Cisco Nexus 3232C Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Zur Installation und Konfiguration der Hardware für einen 3232C Cluster Switch sind die folgenden Schritte auszuführen:

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:setup_worksheet_3232c.html["Vervollständigen Sie das Verkabelungsarbeitsblatt"]
[role="quick-margin-para"]
Das Beispiel-Verkabelungs-Arbeitsblatt enthält Beispiele für empfohlene Portzuweisungen von den Switches zu den Controllern.  Das leere Arbeitsblatt dient als Vorlage, die Sie beim Einrichten Ihres Clusters verwenden können.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:install-switch-3232c.html["Installieren Sie den Schalter"]
[role="quick-margin-para"]
Der 3232C Switch wird installiert.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:install-cisco-nexus-3232c.html["Installieren Sie den Switch in einem NetApp -Schrank."]
[role="quick-margin-para"]
Den 3232C Switch und die Durchführungsplatte in einem NetApp Schrank nach Bedarf installieren.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]link:cabling-considerations-3232c.html["Kabel und Konfiguration prüfen"]
[role="quick-margin-para"]
Unterstützung für NVIDIA Ethernet-Ports prüfen.
