= Konfigurationsanforderungen für Cisco Nexus 92300YC Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Für die Installation und Wartung des Cisco Nexus 92300YC Switches empfiehlt sich eine Überprüfung aller Konfigurations- und Netzwerkanforderungen.

Wenn Sie ONTAP -Cluster mit mehr als zwei Knoten aufbauen möchten, benötigen Sie zwei unterstützte Cluster-Netzwerk-Switches.  Sie können zusätzliche Management-Schalter verwenden, die optional sind.



[[configuration-requirements]]
== Konfigurationsanforderungen

Zur Konfiguration Ihres Clusters benötigen Sie die entsprechende Anzahl und Art von Kabeln und Kabelsteckern für Ihre Switches. Abhängig vom Typ des Switches, den Sie initial konfigurieren, ist eine Verbindung zum Konsolenport des Switches mit dem mitgelieferten Konsolenkabel erforderlich; zudem müssen spezifische Netzwerkinformationen bereitgestellt werden.



[[network-requirements]]
== Netzwerkanforderungen

Für alle Switch-Konfigurationen werden die folgenden Netzwerkinformationen benötigt:

* IP-Subnetz für den Verwaltungsnetzwerkverkehr
* Hostnamen und IP-Adressen für jeden Speichersystem-Controller und alle entsprechenden Switches
* Die meisten Speichersystemcontroller werden über die e0M-Schnittstelle verwaltet, indem eine Verbindung zum Ethernet-Serviceport (Schraubenschlüsselsymbol) hergestellt wird. Bei AFF A800 und AFF A700 Systemen verwendet die e0M-Schnittstelle einen dedizierten Ethernet-Port.


.Ähnliche Informationen
* Weitere Informationen zu Switch-Ports finden Sie in der link:https://hwu.netapp.com/Switch/Index["Hardware Universe"^].
* Weitere Informationen zu den Installationsanforderungen für Netzwerk-Switches finden Sie unter link:https://kb.netapp.com/Support/General_Support/What_additional_information_do_I_need_to_install_my_equipment_that_is_not_in_HWU["Welche zusätzlichen Informationen benötige ich für die Installation meiner Geräte, die nicht in HWU enthalten sind?"^].
