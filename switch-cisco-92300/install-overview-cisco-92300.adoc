= Installations- und Einrichtungsworkflow für Cisco Nexus 92300YC Cluster Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Mit diesem Workflow lassen sich Cisco Nexus 92300YC Cluster Switches in einer ONTAP Umgebung installieren und konfigurieren. Der 92300YC unterstützt ONTAP Cluster mit mehr als zwei Knoten.

Die folgenden Arbeitsschritte dienen der Installation und Einrichtung Ihres Cisco Nexus 92300YC Switch.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:configure-reqs-92300.html["Konfigurationsanforderungen"]
[role="quick-margin-para"]
Die Konfigurationsanforderungen für den 92300YC Cluster-Switch werden dargestellt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:required-documentation-92300.html["Erforderliche Dokumentation"]
[role="quick-margin-para"]
Die spezifische Dokumentation zu Switch und Controller bietet Informationen zur Einrichtung Ihrer 92300YC Switches und des ONTAP Clusters.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:smart-call-home-92300.html["Anforderungen für Smart Call Home"]
[role="quick-margin-para"]
Überprüfen Sie die Anforderungen für die Cisco Smart Call Home-Funktion, die zur Überwachung der Hardware- und Softwarekomponenten in Ihrem Netzwerk verwendet wird.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]link:install-hardware-workflow.html["Installieren Sie die Hardware"]
[role="quick-margin-para"]
Installieren Sie die Switch-Hardware.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Fünf"]link:configure-software-overview-92300-cluster.html["Konfigurieren der Software"]
[role="quick-margin-para"]
Konfigurieren Sie die Switch-Software.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sechs"]link:../switch-cshm/config-overview.html["CSHM konfigurieren"]
[role="quick-margin-para"]
Konfigurieren Sie die Zustandsüberwachung der Switches.
