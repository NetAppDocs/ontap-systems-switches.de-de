= FRUs austauschen Cisco Nexus 9364D-GX2A
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ihr Cisco Nexus 9364D-GX2A Switch verfügt über vor Ort austauschbare Einheiten (FRUs), die bei einem Defekt ersetzt werden können.

.Informationen zu diesem Vorgang
Der Cisco Nexus 9364D-GX2A Switch verfügt über die folgenden FRUs:

* Lüftermodul (insgesamt 4)
* Netzteilmodul (2 insgesamt)
* OSFP/QSFP Transceivermodule (64 feste 400GbE Ports)


.Schritte
. Zur Cisco Website für die  https://www.cisco.com/c/en/us/td/docs/dcn/hw/nx-os/nexus9000/9364d-gx2a/cisco-nexus-9364d-gx2a-nx-os-mode-switch-hardware-installation-guide.html?dtid=osscdc000283&linkclickid=srch&scid=srch-9364d-gx2a-hw-guide#id_111902["Cisco Nexus 9364D-GX2A NX-OS-Modusschalter – Hardwareinstallationshandbuch"^].
. Im Abschnitt „Komponenten austauschen“ finden Sie die FRU-Prozeduren.
. Das entsprechende Verfahren zum Austausch der defekten FRU ist zu befolgen.


.Wie geht es weiter?
Nachdem Sie die entsprechende FRU-Prozedur auf der Cisco-Website abgeschlossen haben, kann der normale Betrieb fortgesetzt werden.
