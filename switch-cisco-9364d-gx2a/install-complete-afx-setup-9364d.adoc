= Die AFX Systemeinrichtung abschließen, Cisco Nexus 9364D-GX2A
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nachdem die Konfigurationsprozeduren für den Cisco Nexus 9364D-GX2A Switch abgeschlossen sind, wird die Dokumentationsseite des AFX-Systems aufgerufen, um die Storage Shelves und Controller in Ihrem AFX 1K oder AFX 2K System einzuschalten, die Switch-Konnektivität zu überprüfen und die AFX Systemeinrichtung abzuschließen.

.Bevor Sie beginnen
* Die Switch-Konfigurationsprozeduren im link:configure-switch-workflow-9364d.html["Switch-Workflow konfigurieren"] müssen abgeschlossen sein.
* Jeder Switch muss mit einer Konsole verbunden sein oder es muss Fernzugriff auf jeden Switch bestehen.


.Schritte
. Führen Sie die Einschalt- und Einrichtungsschritte für Ihr AFX 1K oder AFX 2K System durch:
+
** Für ein AFX 1K System siehe das link:https://docs.netapp.com/us-en/ontap-afx/install-setup/power-on-hardware.html["Schalten Sie Ihr AFX 1K-Speichersystem ein"^] Verfahren.
** Für ein AFX 2K-System siehe das link:https://docs.netapp.com/us-en/ontap-afx/install-afx-2k/power-on-hardware.html["AFX 2K Storage-System einschalten"^] Verfahren.




.Wie geht es weiter?
Nachdem die Speicherregale und Controller eingeschaltet und die Einrichtung des AFX 1K oder AFX 2K Systems abgeschlossen wurden, ist das AFX System einsatzbereit.
