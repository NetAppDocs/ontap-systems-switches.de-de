= Informationen zu den Wartungsoptionen für den Cisco Nexus 9364D-GX2A Switch
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die verfügbaren Wartungsaufgaben für Cisco Nexus 9364D-GX2A Switches umfassen den Austausch defekter Switch-Komponenten (FRUs), den Austausch eines defekten Switches sowie das Zurücksetzen eines Switches auf die Werkseinstellungen.

Die folgenden Wartungsaufgaben können an einem Switch durchgeführt werden:

* link:replace-9364d-cluster.html["Einen Switch austauschen"]
* link:maintain-replace-frus-9364d.html["FRUs austauschen"]
* link:maintain-reset-switch-9364d.html["Einen Switch auf die Werkseinstellungen zurücksetzen"]
