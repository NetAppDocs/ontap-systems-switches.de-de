= Verkabelungs- und Konfigurationsanforderungen für den Cisco Nexus 9808 Switch prüfen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Verkabelungs- und Konfigurationsanforderungen für Cisco Nexus 9808 Switches sollten vor der Installation als Teil eines neuen AFX 2K Systems, dem Austausch eines Supervisor-Moduls oder dem Zurücksetzen eines Switches auf die Werkseinstellungen überprüft werden.



[[hard-code-the-speed-on-breakout-ports]]
== Die Geschwindigkeit auf Breakout-Ports fest codieren

Die Breakout-Ports des Switches (4x100GbE) müssen fest auf 100GbE konfiguriert werden. Wenn die Geschwindigkeit nicht fest konfiguriert wird, kommen die Ports nicht hoch und befinden sich in einem Fehler-Deaktivierungszustand.

Beispielsweise wird 100GbE an den Breakout-Ports 19-35 fest konfiguriert, indem im Konfigurationsmodus wie folgt vorgegangen wird. Im Beispiel werden die Befehle auf den ersten Switch (cs1) angewendet. Diese Befehle werden für den zweiten Switch wiederholt.

[listing, subs="+quotes"]
----
(cs1)# *configure terminal*
Enter configuration commands, one per line. End with CNTL/Z.
(cs1)(config)# *interface e1/19/1-4,e1/20/1-4,e1/21/1-4,e1/22/1-4,e1/23/1-4,e1/24/1-4,e1/25/1-4,e1/26/1-4,e1/27/1-4,e1/28/1-4,e1/29/1-4,e1/30/1-4,e1/31/1-4,e1/32/1-4,e1/33/1-4,e1/34/1-4,e1/35/1-4*
(cs1)(config-if)# *speed 100000*
(cs1)(config-if)# *no negotiate auto*
(cs1)(config-if)# *exit*
(cs1)(config)# *exit*
(cs1)# *copy running-config startup-config*
----
