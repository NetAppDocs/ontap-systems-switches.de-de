= Informationen zur Installation oder Aktualisierung des RCF auf dem Cisco Nexus 9808 Switch
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Referenzkonfigurationsdatei (RCF) auf Cisco Nexus 9808 Switches installieren oder aktualisieren. Eine neue RCF für AFX 2K Systeminstallationen oder den Austausch von Supervisor-Modulen installieren oder eine vorhandene RCF aktualisieren, um neue Hardware oder ONTAP Versionen zu unterstützen.


NOTE: Die Installation oder Aktualisierung von RCF ist unabhängig von der Installation oder Aktualisierung von NX-OS. Wenn sowohl NX-OS als auch RCF installiert oder aktualisiert werden, empfiehlt es sich, NX-OS zuerst zu installieren oder zu aktualisieren.



[[understand-the-supported-rcf-versions]]
=== Informationen zu den unterstützten RCF Versionen

Die Version von ONTAP, die auf Ihrem AFX-System ausgeführt wird, und die Version von NX-OS auf Ihren Cisco Nexus 9808 Switches bestimmen die unterstützten Versionen von RCF für Ihre Switches. RCF-Versionen verfügen über voreingestellte Portgeschwindigkeitskonfigurationen, die festlegen, wie viele Switch-Ports sich im Breakout-Modus (4x100GbE) und im Nicht-Breakout-Modus befinden.

[NOTE]
====
Die aktuelle Liste der unterstützten RCF Versionen befindet sich unter link:https://mysupport.netapp.com/site/info/cisco-ethernet-switch["NetApp Cisco Ethernet-Switches"^].

Informationen zu den Switch-Ports sind auch in der link:https://hwu.netapp.com["NetApp Hardware Universe"^] zu finden.

====

NOTE: Spezifische Details zur Port- und VLAN-Nutzung finden Sie im Banner und im Abschnitt „Wichtige Hinweise“ Ihres RCF. Weitere Informationen finden Sie unter link:https://mysupport.netapp.com/site/info/cisco-ethernet-switch["NetApp Cisco Ethernet-Switches"^].

Die folgende Tabelle zeigt beispielsweise die voreingestellten Gruppen der Switch-Ports, ihre Portgeschwindigkeiten und die Nutzung basierend auf RCF Version 10.1.

[cols="1,2"]
|===
| Switch Portgruppen | Portgeschwindigkeiten und Nutzung 


 a| 
Ethernet1/1 bis Ethernet1/18
 a| 
400GbE Modus für Intra-cluster, HA und Storage shelf Verbindungen



 a| 
Ethernet1/19 bis Ethernet1/35
 a| 
4x100GbE Modus für Intra-cluster-, HA- und Storage-Verbindungen



 a| 
Ethernet1/36
 a| 
400GbE Intra-Cluster ISL-Verbindungen

|===


[[change-port-speed-configuration]]
=== Portgeschwindigkeit konfigurieren

Bei Switches mit RCF 10.1 und höher kann die Portgeschwindigkeitskonfiguration geändert werden, um die Anzahl der Switch-Ports im Breakout-Modus (4x100GbE) und im Nicht-Breakout-Modus (400GbE) anzupassen, wenn eine andere Portgeschwindigkeitskonfiguration für das AFX System erforderlich ist. Alle Portänderungen erfolgen pro aktuell verwendeter Linecard.

Diese Änderung wird im Rahmen der RCF Installation oder des RCF Upgrade Verfahrens durchgeführt. Die Verfahren enthalten Schritte, die auf diese Seite verweisen.

Sie geben die Befehle auf beiden Switches ein.

[cols="1,2"]
|===
| Portgeschwindigkeiten ändern | Schritte 


 a| 
Nicht-Breakout-Ports in Breakout-Ports ändern
 a| 
. Im CLI in den Konfigurationsmodus wechseln.
. Portgeschwindigkeiten und Breakout-Modi auf den Switches anpassen:
+
Um Breakout-Ports festzulegen, den  `interface breakout module` Befehl verwenden.

+
Beispielsweise können die 400GbE Modus Ports 19-22 als Breakout-Ports (4x100GbE) festgelegt werden, indem Folgendes verwendet wird:

+
`interface breakout module 1 port 19-22 map 100g-4x`

. Die Portliste mit den neuen Ports anpassen, die das Portprofil für die gewünschte Portgeschwindigkeit verwenden müssen.
+
Beispielsweise kann die Portliste mit den neuen Ports 19-22 für das 100G Speed Port-Profil wie folgt angepasst werden:

+
`interface e1/19/1-4, e1/20/1-4, e1/21/1-4, e1/22/1-4`

. Die Breakout-Ports (4x100GbE) des Switches sind fest auf 100GbE zu konfigurieren. Wenn die Geschwindigkeit nicht fest konfiguriert wird, werden die Ports nicht aktiviert und befinden sich in einem fehlerdeaktivierten Zustand:
+
`speed 100000`

+
`no negotiate auto`





 a| 
Breakout-Ports wieder in Nicht-Breakout-Ports umwandeln
 a| 
. Im CLI in den Konfigurationsmodus wechseln.
. Um Breakout-Ports wieder in Nicht-Breakout-Ports zurückzusetzen, wird der  `no interface breakout` Befehl im Konfigurationsmodus verwendet.
+
Beispielsweise können die Ports 19-22 wieder in den 400GbE Modus versetzt werden, indem Folgendes verwendet wird:

+
`no interface breakout module 1 port 19-22`



|===

+
Auf der NetApp Support-Website finden Sie die Tabelle zur Switch-Kompatibilität, in der die unterstützten ONTAP und RCF-Versionen aufgeführt sind.  Beachten Sie, dass zwischen der Befehlssyntax in der RCF und der Syntax in bestimmten Versionen von NX-OS Befehlsabhängigkeiten bestehen können.

* link:https://www.cisco.com/c/en/us/support/switches/nexus-9000-series-switches/series.html["Cisco Nexus 9000 Series Switches"^]
+
Die vollständige Dokumentation zu den Upgrade- und Downgrade-Verfahren für Cisco -Switches finden Sie in den entsprechenden Software- und Upgrade-Leitfäden auf der Cisco -Website.
