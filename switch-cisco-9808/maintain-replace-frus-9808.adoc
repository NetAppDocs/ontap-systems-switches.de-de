= FRUs ersetzen - Cisco Nexus 9808
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ihr Cisco Nexus 9808 Switch verfügt über austauschbare Einheiten (FRUs), die bei einem Defekt ersetzt werden können.

.Informationen zu diesem Vorgang
Der Cisco Nexus 9808 Switch verfügt über die folgenden FRUs:

* *Schaumstoff-Luftfilter für die Chassis-Türen* (insgesamt 2): Die Türen sind mit vorinstallierten Luftfiltern ausgestattet. Die Luftfilter sollten alle 3 Monate überprüft und bei Bedarf ausgetauscht werden.
* *Supervisor module* (1 oder 2 insgesamt, abhängig davon, wie der Switch bestellt wurde): Wenn zwei Supervisor module im Switch installiert sind, fungiert eines als aktives Modul und das andere als Standby-Modul. Wenn das aktive Supervisor module entfernt wird, macht der Switch das Standby Supervisor module automatisch zum aktiven Modul. Wenn im Switch nur ein Supervisor module installiert ist, kann während des Betriebs ein neues Supervisor module in den freien Supervisor-Steckplatz eingesetzt werden.
* *Leitungskarten* (insgesamt 8, jede mit 16 festen 400GbE-Ports): Der Switch arbeitet mit einer oder mehreren Leitungskarten, die im Chassis installiert sind.
* *Lüfterablage* (2 insgesamt)
* *Fabric-Modul* (2 insgesamt)
* *Komponenten des Netzteils* (2 insgesamt)
* *Lüftermodul* (6 insgesamt)
* *OSFP/QSFP Transceivermodule* (32 feste 400GbE Ports)
