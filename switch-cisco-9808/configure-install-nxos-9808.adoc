= NX-OS auf dem Cisco Nexus 9808 Switch installieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NX-OS auf Cisco Nexus 9808 Switches für neue AFX 2K Systeminstallationen, Supervisor-Modul-Austausch oder beim Zurücksetzen eines Switches auf die Werkseinstellungen installieren.

.Bevor Sie beginnen
* Der/Die Schalter müssen eingeschaltet sein und die link:configure-complete-initial-setup-9808.html["Abschließen der Ersteinrichtung des Switches"]Prozedur muss abgeschlossen sein.
* Wenn NX-OS im Rahmen einer Neuinstallation eines AFX Systems oder eines Austauschs eines Supervisor-Moduls auf dem/den Switch(es) installiert wird, sollte überprüft werden, ob die Version von NX-OS auf dem/den Switch(es) die aktuelle, von NetApp unterstützte Version ist.
+
** Wenn Ihre Switches die aktuell von NetApp unterstützte Version verwenden, ist keine Installation von NX-OS erforderlich. Die Referenz-Konfigurationsdatei (RCF) muss installiert werden. Es wird mit der link:configure-install-upgrade-rcf-overview-9808.html["Übersicht zur Installation oder Aktualisierung des RCF"] begonnen.
** Wenn auf Ihrem/Ihren Switch(es) nicht die aktuelle, von NetApp unterstützte Version vorhanden ist, wird mit diesem Verfahren die Installation von NX-OS fortgesetzt.


* Wenn NX-OS auf einem Switch im Rahmen eines Switch-Austauschs oder eines Zurücksetzens des Switches auf die Werkseinstellungen installiert wird, sollte sichergestellt sein, dass der Cluster voll funktionsfähig ist, das heißt, dass keine Fehler in den Protokollen oder ähnliche Probleme vorliegen.



NOTE: Wenn NX-OS im Rahmen einer Neuinstallation eines AFX-Systems installiert wird, kann diese Anforderung übersprungen werden, da die Controller in Ihrem AFX-System zu diesem Zeitpunkt der Installation und Einrichtung des AFX-Systems noch nicht eingeschaltet sind.

.Informationen zu diesem Vorgang
* Die auf Ihrem AFX-System ausgeführte ONTAP-Version bestimmt die unterstützten Versionen von NX-OS für Ihre Switches.
+
** Für Switches in einem AFX 2K-System wird der Betrieb mit ONTAP 9.19.1GA oder höher und NX-OS 10.6(3) oder höher unterstützt.
+
Die aktuelle Liste der unterstützten NX-OS Versionen ist unter link:https://mysupport.netapp.com/site/info/cisco-ethernet-switch["NetApp Cisco Ethernet-Switches"^] zu finden.



* Dieses Verfahren erfordert ausschließlich die Verwendung von Cisco Nexus 9000 Series Switches Befehlen.
* In den Beispielen dieses Verfahrens wird der erste Switch als cs1 und der zweite Switch als cs2 bezeichnet.
* Wenn im Rahmen einer Neuinstallation eines AFX 2K Systems Switches installiert wurden, wird das NX-OS auf dem ersten Switch (cs1) installiert und anschließend werden die Schritte für den zweiten Switch (cs2) mit dieser Vorgehensweise wiederholt.
* Die in diesem Verfahren gezeigten Beispiele gelten für AFX 2K Systeme mit Switches, auf denen RCF 10.1 ausgeführt wird. Die Eingabe und Ausgabe kann je nach Ihrer RCF Version variieren.




[[step-1-prepare-to-install-the-nx-os]]
== Schritt 1: Vorbereitung der Installation von NX-OS

Die Installation von NX-OS auf dem/den Switch(es) wird vorbereitet, indem sichergestellt wird, dass Zugriff auf einen Server mit der unterstützten NX-OS-Version besteht, NX-OS heruntergeladen wird, eine Verbindung zum Management-Netzwerk für die Dateiübertragung hergestellt wird und anschließend die Konnektivität zum Server überprüft wird.

.Schritte
. Sie benötigen Zugriff auf einen HTTP-, SFTP-, FTP- oder TFTP-Server. Zugriff auf einen dieser Server ermöglicht das Herunterladen einer unterstützten Version von NX-OS.
. Laden Sie die richtige Version von NX-OS und das EPLD-Image von der  https://software.cisco.com/download/home["Cisco -Software-Download"^] Seite auf den/die Switch(es) herunter.
. Den Switch mit dem Management-Netzwerk (für die Dateiübertragung) verbinden.
. Die Konnektivität zum Server, auf dem NX-OS gehostet wird, lässt sich mit dem  `ping`Befehl überprüfen:
+
`ping <IP address>`

+
.Beispiel anzeigen
[%collapsible]
====
Dieses Beispiel bestätigt, dass der Switch den Server unter der IP-Adresse 172.19.2.1 erreichen kann:

[listing, subs="+quotes"]
----
cs1# *ping 172.19.2.1*
Pinging 172.19.2.1 with 0 bytes of data:

Reply From 172.19.2.1: icmp_seq = 0. time= 5910 usec.
----
====




[[step-2-install-the-nx-os-and-epld-image]]
== Schritt 2: Installation des NX-OS- und EPLD-Images

Das NX-OS- und EPLD-Image wird auf dem ersten Switch (cs1) installiert, indem die NX-OS- und EPLD-Image-Versionen installiert und überprüft werden. Im Falle einer Installation von NX-OS als Teil einer neuen AFX Systeminstallation werden diese Schritte anschließend auf dem zweiten Switch (cs2) wiederholt.

. Kopieren des kombinierten NX-OS- und EPLD-Images auf den ersten Switch:
+
`copy <protocol>: bootflash: vrf management`

+
.Beispiel anzeigen

. Wenn das NX-OS im Rahmen einer neuen AFX-Systeminstallation installiert wird, sind diese Schritte zu wiederholen, um das NX-OS- und EPLD-Image auf dem Switch cs2 zu installieren.


.Wie geht es weiter?
Nachdem Sie NX-OS auf Ihrem/Ihren Switch(es) installiert haben, wird RCF beginnend mit der link:configure-install-upgrade-rcf-overview-9808.html["Übersicht zur Installation oder Aktualisierung des RCF"] installiert.
