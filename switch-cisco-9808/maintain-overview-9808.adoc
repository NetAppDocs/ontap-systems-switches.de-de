Die folgenden Wartungsaufgaben können an einem Switch durchgeführt werden:

* link:maintain-replace-frus-9808.html["FRUs austauschen"]
* link:maintain-reset-switch-9808.html["Einen Switch auf die Werkseinstellungen zurücksetzen"]
