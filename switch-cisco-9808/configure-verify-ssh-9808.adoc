= SSH für die Protokollerfassung auf dem Cisco Nexus 9808 Switch überprüfen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es sollte überprüft werden, dass SSH auf Cisco Nexus 9808 Switches aktiviert ist, damit die Funktionen Ethernet Switch Health Monitor (CSHM) und Log Collection unterstützt werden.

.Bevor Sie beginnen
Sie müssen über die serielle Konsole mit dem Switch verbunden sein.

.Schritte
. Überprüfen Sie, ob SSH aktiviert ist:
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. Überprüfen Sie, ob die SSH-Schlüssel aktiviert sind:
+
`show ssh key`

+

.Wie geht es weiter?
* Nachdem Sie überprüft haben, dass SSH für die Protokollerfassung aktiviert ist, link:../switch-cshm/cshm-overview.html["Konfiguration der Zustandsüberwachung von Ethernet Switches"].
* Nachdem die Zustandsüberwachung für Ethernet Switches konfiguriert wurde, besteht die Möglichkeit, die Cisco Smart Call Home Supportfunktion zu nutzen link:configure-smart-call-9808.html["Smart Call Home konfigurieren"].
* Wenn Sie Ihren Switch im Rahmen einer Neuinstallation eines AFX 2K-Systems konfiguriert haben, müssen Sie link:install-complete-afx-setup-9808.html["Die AFX Systemeinrichtung abschließen"].
