= SSH für die Protokollerfassung überprüfen, Cisco Nexus 9808
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn die Switches im Rahmen einer Neuinstallation eines AFX 2K Systems, eines Supervisor-Modul-Austauschs oder einer Wiederherstellung der Werkseinstellungen konfiguriert werden, ist für die Nutzung der Protokollerfassungsfunktion des Ethernet Switch Health Monitor (CSHM) zu überprüfen, ob SSH auf den Switches aktiviert ist.

.Bevor Sie beginnen
Sie müssen über die serielle Konsole mit dem Switch verbunden sein.

.Schritte
. Überprüfen Sie, ob SSH aktiviert ist:
+
[listing, subs="+quotes"]
----
(switch) *show ssh server*
ssh version 2 is enabled
----
. Überprüfen Sie, ob die SSH-Schlüssel aktiviert sind:
+
`show ssh key`
