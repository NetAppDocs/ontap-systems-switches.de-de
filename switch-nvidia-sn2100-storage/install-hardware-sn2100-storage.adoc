= Hardware für den NVIDIA SN2100 Speicherschalter installieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die NVIDIA SN2100 Storage Switch-Hardware wird gemäß der NVIDIA-Dokumentation installiert. Die Hardwareinstallation ist der erste Schritt vor der Konfiguration des Switches für den Betrieb im Speichernetzwerk.

Befolgen Sie diese Schritte, um Ihre SN2100-Switches einzurichten und zu konfigurieren. Ausführliche Anweisungen finden Sie in der Dokumentation von NVIDIA.

.Schritte
. Überprüfen Sie dielink:configure-reqs-sn2100-storage.html["Konfigurationsanforderungen"] Die
. Befolgen Sie die Anweisungen in der link:https://networking-docs.nvidia.com/sn2000hw/latest/installation["NVIDIA Switch Installationsanleitung"^].


.Wie geht es weiter?
Nachdem Sie Ihre Hardware installiert haben, können Sielink:cabling-considerations-sn2100-storage.html["Verkabelung und Konfiguration überprüfen"] Anforderungen.
