= NS224-Laufwerksschächte als Switch-gebundener Speicher für NVIDIA SN2100 Storage Switches verkabeln
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NS224-Laufwerksshelfs als Switch-gebundener Speicher mithilfe von NVIDIA SN2100 Storage Switches verkabeln, wenn direkt angeschlossener Speicher für Ihre Konfiguration nicht geeignet ist.

* Kabel NS224 treibt Regale über Speicherschalter an:
+
https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580["Informationen zur Verkabelung von NS224-Laufwerksschächten mit Switch-Anschluss."^]

* Installieren Sie Ihre Speicherschalter:
+
https://docs.netapp.com/us-en/ontap-systems-switches/index.html["AFF und FAS Schalterdokumentation"^]

* Bestätigen Sie unterstützte Hardware, wie Speicherschalter und Kabel, für Ihr Plattformmodell. Siehe die link:https://hwu.netapp.com/["Hardware Universe"^] für Details.
