= RCF-Skript auf NVIDIA SN2100 Storage Switches installieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das Skript für die Referenzkonfigurationsdatei (RCF) wird auf NVIDIA SN2100 Storage Switches installiert, um Portzuweisungen und Netzwerkeinstellungen zu konfigurieren.

.Bevor Sie beginnen
Vor der Installation des RCF-Skripts muss Folgendes auf dem Switch verfügbar sein:

* Eine unterstützte Version von Cumulus Linux ist installiert.
* IP-Adresse des Management-Ports, Subnetzmaske und Standardgateway werden per DHCP definiert oder manuell konfiguriert.


.RCF Skriptversion
Die Auswahl der geeigneten Storage RCF Skriptversion richtet sich nach Ihrer aktuellen ONTAP und Cumulus Linux Version. Der Download der RCFs erfolgt von der  https://mysupport.netapp.com/site/info/nvidia-cluster-switch["NVIDIA SN2100 Software-Download"^]Seite.

.Zu den Beispielen
Das folgende Beispielverfahren zeigt, wie Sie das RCF-Skript für Storage-Switches herunterladen und anwenden.

. Kopieren Sie das RCF-Python-Skript auf den Switch:

cumulus@cumulus:mgmt:/tmp$ *scp <user>@<host:/<path>/RCF-v1.14-MSN2100-ST1*

----
. Anwendung des RCF Python-Skripts *RCF-v1.14-MSN2100-ST1*:
+
[listing, subs="+quotes"]
----
cumulus@cumulus:mgmt:/tmp$ *RCF-v1.14-MSN2100-ST1*
[sudo] password for cumulus:
...
Step 1: Creating the banner file

Das RCF-Skript führt die oben aufgeführten Schritte aus.

+

NOTE: Bei Problemen mit RCF-Python-Skripten, die nicht behoben werden können, wenden Sie sich bitte an [Kontaktinformationen einfügen]. https://mysupport.netapp.com/["NetApp Support"^] um Unterstützung zu erhalten.

. Die Controller Storage Ports und die NS224 Shelf Ports werden an die Switches angeschlossen.
