= NX-OS auf dem Cisco Nexus 9332D-GX2B Switch installieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NX-OS auf Cisco Nexus 9332D-GX2B Switches für neue AFX 1K oder AFX 2K Systeminstallationen, Switch-Austausch oder beim Zurücksetzen eines Switches auf die Werkseinstellungen installieren.

.Bevor Sie beginnen
* Der/Die Switches müssen eingeschaltet sein und die link:configure-complete-initial-setup-9332d.html["Abschließen der Ersteinrichtung des Switches"]Prozedur muss abgeschlossen sein.
* Wenn NX-OS im Rahmen einer Neuinstallation eines AFX Systems oder eines Switch-Austauschs auf einem oder mehreren Switches installiert wird, sollte überprüft werden, ob die Version von NX-OS auf dem/den Switch(es) die aktuelle, von NetApp unterstützte Version ist.
+
** Wenn Ihre Switches die aktuell von NetApp unterstützte Version verwenden, ist keine Installation von NX-OS erforderlich. Die Installation des RCF ist erforderlich. Es wird mit der link:configure-install-upgrade-rcf-overview-9332d.html["Übersicht zur Installation oder Aktualisierung des RCF"] begonnen.
** Wenn auf Ihrem/Ihren Switch(es) nicht die aktuelle, von NetApp unterstützte Version vorhanden ist, wird mit diesem Verfahren die Installation von NX-OS fortgesetzt.


* Wenn NX-OS auf einem Switch im Rahmen eines Switch-Austauschs oder eines Zurücksetzens des Switches auf die Werkseinstellungen installiert wird, sollte sichergestellt sein, dass der Cluster voll funktionsfähig ist, das heißt, dass keine Fehler in den Protokollen oder ähnliche Probleme vorliegen.



NOTE: Wenn NX-OS im Rahmen einer Neuinstallation eines AFX-Systems installiert wird, kann diese Anforderung übersprungen werden, da die Controller in Ihrem AFX-System zu diesem Zeitpunkt der Installation und Einrichtung des AFX-Systems noch nicht eingeschaltet sind.

.Informationen zu diesem Vorgang
* Die auf Ihrem AFX-System ausgeführte ONTAP-Version bestimmt die unterstützten Versionen von NX-OS für Ihre Switches.
+
** Für Switches in einem AFX 1K-System, auf denen eine beliebige unterstützte Version von ONTAP ausgeführt wird, wird NX-OS 10.4.2 und höher unterstützt.
** Für Switches in einem AFX 2K-System, auf denen ONTAP 9.19.1GA oder höher ausgeführt wird, wird NX-OS 10.6 und höher unterstützt.
+
Die aktuelle Liste der unterstützten NX-OS Versionen befindet sich auf der link:https://mysupport.netapp.com/site/info/cisco-ethernet-switch["NetApp Cisco Ethernet-Switches"^] Seite.



* Dieses Verfahren erfordert ausschließlich die Verwendung von Cisco Nexus 9000 Series Switches Befehlen.
* In den Beispielen dieses Verfahrens wird der erste Switch als cs1 und der zweite Switch als cs2 bezeichnet.
* Wenn Sie Switches im Rahmen einer Neuinstallation eines AFX 1K oder AFX 2K Systems installiert haben, sieht dieses Verfahren vor, dass das NX-OS auf dem ersten Switch (cs1) installiert wird und die Schritte anschließend für den zweiten Switch (cs2) wiederholt werden.
* Die in diesem Verfahren gezeigten Beispiele gelten für AFX 1K Systeme mit Switches, auf denen RCF 10.0 läuft. Bei einem AFX 2K System können die Ein- und Ausgaben abweichen.




[[step-1-prepare-to-install-the-nx-os]]
== Schritt 1: Vorbereitung der Installation von NX-OS

Die Installation von NX-OS auf dem/den Switch(es) wird vorbereitet, indem sichergestellt wird, dass Zugriff auf einen Server mit der unterstützten NX-OS-Version besteht, NX-OS heruntergeladen wird, eine Verbindung zum Management-Netzwerk für die Dateiübertragung hergestellt wird und anschließend die Konnektivität zum Server überprüft wird.

.Schritte
. Sie benötigen Zugriff auf einen HTTP-, FTP- oder TFTP-Server. Zugriff auf einen dieser Server ermöglicht das Herunterladen einer unterstützten Version von NX-OS.
. Laden Sie die richtige Version von NX-OS und das EPLD-Image von der  https://software.cisco.com/download/home["Cisco -Software-Download"^] Seite auf den/die Switch(es) herunter.
. Den Switch mit dem Management-Netzwerk (für die Dateiübertragung) verbinden.
. Die Konnektivität zum Server, auf dem NX-OS gehostet wird, lässt sich mit dem Befehl „ping“ überprüfen.
+
`ping <IP address>`

+
.Beispiel anzeigen
[%collapsible]
====
Dieses Beispiel bestätigt, dass der Switch den Server unter der IP-Adresse 172.19.2.1 erreichen kann:

[listing, subs="+quotes"]
----
cs1# *ping 172.19.2.1*
Pinging 172.19.2.1 with 0 bytes of data:

Reply From 172.19.2.1: icmp_seq = 0. time= 5910 usec.
----
====




[[step-2-install-the-nx-os-and-epld-image]]
== Schritt 2: Installation des NX-OS- und EPLD-Images

Das NX-OS und EPLD Image wird auf dem ersten Switch (cs1) installiert und überprüft; diese Schritte werden anschließend auf dem zweiten Switch (cs2) wiederholt, wenn das NX-OS im Rahmen einer neuen AFX Systeminstallation installiert wird.

. Das NX-OS- und EPLD-Image installieren.
+
Wählen Sie die Registerkarte, die auf Ihre Situation zutrifft:

+
** Installation von 10.4(2)F
** Die Installation von Version 10.6(3)F oder einer späteren Version




[role="tabbed-block"]
====

. Die NX-OS- und EPLD-Images installieren.
+
[NOTE]
====
Das EPLD-Image wird beim Upgrade auf NX-OS 10.6(3)F und höher nicht automatisch aktualisiert. Nach Abschluss des Upgrades und nach dem Neustart des Switches muss derselbe Upgrade `install all`Befehl erneut ausgeführt werden.

** Der zweite Upgrade-Durchlauf verifiziert die Aktualisierung, überspringt aber das NX-OS Upgrade; nur das EPLD Image wird aktualisiert.
** Wenn Sie bereits auf NX-OS 10.6(3)F und höher aktualisiert haben, werden beide Images gleichzeitig aktualisiert.
