= Überblick behalten, Cisco Nexus 9332D-GX2B
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Warten Sie Ihren Cisco Nexus 9332D-GX2B Switch, um langfristige Zuverlässigkeit und optimale Leistung sicherzustellen. Es können Wartungsaufgaben wie der Austausch defekter Switch-Komponenten (FRUs), der Austausch eines defekten Switches und das Zurücksetzen eines Switches auf die Werkseinstellungen durchgeführt werden.

Die folgenden Wartungsaufgaben können an einem Switch durchgeführt werden:

* link:replace-9332d-cluster.html["Einen Switch austauschen"]
* link:maintain-replace-frus-9332d.html["FRUs austauschen"]
* link:maintain-reset-switch-9332d.html["Einen Switch auf die Werkseinstellungen zurücksetzen"]
