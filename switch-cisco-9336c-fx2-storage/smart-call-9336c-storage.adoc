= Smart Call Home Anforderungen für Cisco Nexus 9336C-FX2 Speicherswitches prüfen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Anforderungen für die Konfiguration von Smart Call Home auf Cisco Nexus 9336C-FX2 Storage Switches zur Aktivierung automatischer E-Mail-Benachrichtigungen bei kritischen Systemereignissen werden dargestellt.

Cisco Smart Call Home überwacht die Hardware- und Softwarekomponenten Ihres Netzwerks. Bei einer kritischen Systemkonfiguration wird eine E-Mail-Benachrichtigung generiert und alle Empfänger, die in Ihrem Zielprofil konfiguriert sind, werden benachrichtigt.

[NOTE]
====
ONTAP unterstützt die Zustandsüberwachung von Ethernet Switches (CSHM) zur Überwachung der AFX Cluster Switches sowie die Möglichkeit, Diagnoseprotokolle der Switches zu erfassen.

Cisco Smart Call Home ist eine Option, um proaktiven Support bereitzustellen und bei der Lösung eventuell auftretender Probleme mit den Switches zu unterstützen.

====
Bevor Sie Smart Call Home verwenden können, beachten Sie die folgenden Anforderungen:

* Ein E-Mail-Server muss vorhanden sein.
* Der Switch muss über eine IP-Verbindung zum E-Mail-Server verfügen.
* Der Kontaktname (SNMP-Server-Kontakt), die Telefonnummer und die Straßenadresse müssen konfiguriert werden.  Dies ist erforderlich, um den Ursprung der empfangenen Nachrichten zu ermitteln.
* Eine CCO-ID muss mit einem passenden Cisco SMARTnet Servicevertrag für Ihr Unternehmen verknüpft sein.
* Für die Registrierung des Geräts muss der Cisco SMARTnet-Dienst eingerichtet sein.


Der http://www.cisco.com/c/en/us/products/switches/index.html["Cisco Supportseite"^] enthält Informationen zu den Befehlen zur Konfiguration von Smart Call Home.

Smart Call Home kann während der Installation und Einrichtung eines neuen Systems oder nachträglich konfiguriert werden.
