= Softwareinstallations-Workflow für Cisco Nexus 9336C-FX2 und 9336C-FX2-T Storage Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Mit diesem Workflow werden die NX-OS Software und die Referenz-Konfigurationsdatei (RCF) auf Cisco Nexus 9336C-FX2 und 9336C-FX2-T Storage Switches installiert.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"]link:setup-switch-9336c-storage.html["Konfigurieren Sie den Schalter"]
[role="quick-margin-para"]
Konfigurieren Sie die Speicher-Switches 9336C-FX2 und 9336C-FX2-T.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"]link:install-nxos-overview-9336c-storage.html["Bereiten Sie die Installation der NX-OS-Software und des RCF vor."]
[role="quick-margin-para"]
Die Cisco NX-OS-Software und Referenzkonfigurationsdateien (RCFs) müssen auf den Cisco 9336C-FX2- und 9336C-FX2-T-Speicher-Switches installiert werden.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"]link:install-nxos-software-9336c-storage.html["Installieren oder aktualisieren Sie die NX-OS-Software."]
[role="quick-margin-para"]
Laden Sie die NX-OS-Software herunter und installieren oder aktualisieren Sie sie auf den Cisco 9336C-FX2- und 9336C-FX2-T-Speicher-Switches.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"]link:install-upgrade-rcf-overview-9336c-storage.html["Installieren oder aktualisieren Sie die RCF"]
[role="quick-margin-para"]
Installieren oder aktualisieren Sie das RCF, nachdem Sie die Cisco -Switches 9336C-FX2 und 9336C-FX2-T zum ersten Mal eingerichtet haben. Sie können dieses Verfahren auch verwenden, um Ihre RCF-Version zu aktualisieren.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Fünf"]link:configure-ssh-keys.html["SSH-Konfiguration überprüfen"]
[role="quick-margin-para"]
Stellen Sie sicher, dass SSH auf den Switches aktiviert ist, um den Ethernet Switch Health Monitor (CSHM) und die Protokollerfassungsfunktionen zu verwenden.
