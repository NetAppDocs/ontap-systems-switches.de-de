= NX-OS Software auf Cisco Nexus 9336C-FX2 und 9336C-FX2-T Cluster Switches installieren oder aktualisieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die NX-OS Software auf Cisco Nexus 9336C-FX2 und 9336C-FX2-T Cluster Switches installieren oder aktualisieren. NX-OS muss installiert sein, bevor der Switch konfiguriert oder die Referenz Konfigurationsdatei (RCF) installiert werden kann.

Bevor Sie beginnen, führen Sie bitte die folgende Prozedur durch:link:install-nxos-overview-9336c-cluster.html["Bereiten Sie die Installation von NX-OS und RCF vor."] Die


NOTE: NetApp empfiehlt, zunächst ein ONTAP Software-Upgrade abzuschließen und anschließend das Software-Upgrade für Ihre Switches durchzuführen.



[[review-requirements]]
== Überprüfungsanforderungen

.Bevor Sie beginnen
Stellen Sie sicher, dass Sie Folgendes tun:

* Führen Sie den  `show install all impact nxos bootflash:<image_name>.bin` Befehl auf dem Switch aus, um die Auswirkungen der Installation oder Aktualisierung des neuen NX-OS-Software-Images zu überprüfen. Dabei werden die Integrität des Images, erforderliche Neustarts, die Hardwarekompatibilität und ausreichend Speicherplatz geprüft.
* Lesen Sie die Versionshinweise für die Zielversion der NX-OS-Software, um auf spezifische Anforderungen zu prüfen.
* Vergewissern Sie sich, dass Sie eine aktuelle Sicherung der Switch-Konfiguration haben.
* Vergewissern Sie sich, dass Sie einen voll funktionsfähigen Cluster haben (keine Fehler in den Protokollen oder ähnliche Probleme).


.Empfohlene Dokumentation
* link:https://mysupport.netapp.com/site/info/cisco-ethernet-switch["Cisco Ethernet-Switch-Seite"^]
+
In der Switch-Kompatibilitätstabelle finden Sie die unterstützten ONTAP und NX-OS-Versionen.

* link:https://www.cisco.com/c/en/us/support/switches/nexus-9000-series-switches/products-installation-guides-list.html["Anleitungen für Software-Upgrades und -Downgrades"^]
+
Auf der Cisco Website gibt es Anleitungen für Software-Upgrades und -Downgrades.

* link:https://www.cisco.com/c/dam/en/us/td/docs/dcn/tools/nexus-9k3k-issu-matrix/index.html["Cisco Nexus 9000 und 3000 Upgrade- und ISSU-Matrix"^]
+
Bietet Informationen zu unterbrechenden Upgrades/Downgrades der Cisco NX-OS-Software auf Switches der Nexus 9000-Serie basierend auf Ihren aktuellen und Zielversionen.

+
Wählen Sie auf der Seite *Disruptives Upgrade* aus und wählen Sie Ihre aktuelle Version und die Zielversion aus der Dropdown-Liste.



.Zu den Beispielen
Die Beispiele in diesem Verfahren verwenden die folgende Schalter- und Knotennomenklatur:

* Die Namen der beiden Cisco Switches lauten cs1 und cs2.
* Die Knotennamen sind cluster1-01, cluster1-02, cluster1-03 und cluster1-04.
* Die Cluster-LIF-Namen lauten cluster1-01_clus1, cluster1-01_clus2, cluster1-02_clus1, cluster1-02_clus2, cluster1-03_clus1, cluster1-03_clus2, cluster1-04_clus1 und cluster1-04_clus2.
* Der `cluster1::*>` Die Eingabeaufforderung zeigt den Namen des Clusters an.

. Automatische Wiederherstellung der Cluster-LIFs deaktivieren.  Die Cluster-LIFs wechseln zum Partner-Cluster-Switch und bleiben dort, während Sie das Upgrade-Verfahren auf dem Ziel-Switch durchführen:
+
`network interface modify -vserver Cluster -lif * -auto-revert false`

** Upgrade von Version 10.4(6)M oder früher auf Version 10.5(3)(F) oder höher
** Upgrade von 10.5(3)F auf eine neuere Version

. Die NX-OS- und EPLD-Images installieren.
+
[NOTE]
====
Das EPLD-Image wird beim Upgrade auf NX-OS 10.5(3)(F) und höher nicht automatisch aktualisiert. Nach Abschluss des Upgrades und dem Neustart des Switches muss derselbe Upgrade `install all`-Befehl erneut ausgeführt werden.

** Der zweite Upgrade-Durchlauf verifiziert die Aktualisierung, überspringt aber das NX-OS Upgrade; nur das EPLD Image wird aktualisiert.
** Wenn bereits auf NX-OS 10.5(3)(F) oder höher aktualisiert wurde, werden beide Images gleichzeitig aktualisiert.
